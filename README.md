# gaddyh.dev

The personal site of Gaddy H. — independent AI engineer and product builder.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Static-rendered marketing pages
- No backend or client-side data dependencies

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verification

```bash
npm run lint
npx tsc --noEmit
npm run build
```

The homepage lives at `/` and the first case study is at `/work/tamitor`.
